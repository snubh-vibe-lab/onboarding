---

## 이게 뭐예요? (30초)

내가 만든 AI 도구를 동료들과 나누고 싶을 때, **내 repo에 설명서 한 장만** 두면 됩니다.
그러면 매일 밤 봇이 알아서 모아서 공동 Cookbook으로 정리해줘요.
→ **나는 Cookbook에 직접 들어갈 필요가 없습니다. 내 repo만 관리하면 끝.**

## 시작 전 딱 하나 (평생 한 번)

**`snubh-vibe-lab` 조직(organization) 멤버여야 합니다.**
초대 이메일이나 GitHub 알림에서 **Accept(수락)** 를 누르셨으면 이미 끝났습니다.
못 받으셨으면 총무에게 말씀해 주세요.

---

## 도구 하나를 Cookbook에 올리기 — 3단계

### 1단계 — 내 repo가 "공개"인지 확인

- repo 첫 화면, 제목 옆에 회색 글씨로 **Public** 이라고 있으면 → ✅ 통과. 다음 단계로.
- 만약 **Private** 이라고 적혀 있으면 → 혼자 만지지 말고 **테크 헬퍼에게 "공개로 바꿔주세요"** 한마디. (봇은 비공개 repo를 못 읽어요.)

### 2단계 — 표식(Topic) 달기

1. repo 첫 화면 **오른쪽 위 `About`** 글자 옆의 **톱니바퀴 ⚙️** 를 클릭
2. 뜨는 창의 **Topics** 칸에 `snubh-cookbook` 입력 → **Enter** (파란 알약 모양으로 바뀜)
3. 맨 아래 **`Save changes`** 클릭

✅ About 밑에 파란 `snubh-cookbook` 태그가 보이면 성공

### 3단계 — 설명서 파일 만들기

1. repo 첫 화면에서 초록 **`Add file`** → **`Create new file`**
2. 파일 이름 칸에 **정확히** 입력 (점·슬래시 그대로):
   ```
   .cookbook/recipe.md
   ```
3. 아래 **[복사용 양식]** 을 전체 복사해 큰 입력칸에 붙여넣고, **노란 `[...]` 부분만** 내 도구에 맞게 고치기
4. 초록 **`Commit changes`** → 다시 **`Commit changes`**

✅ repo에 `.cookbook` 폴더가 생기면 성공

---

## [복사용 양식] — 이거 그대로 붙여넣고 `[...]` 만 채우세요

```
---
id: [영문소문자-하이픈, 예: radiology-gureport]
title: [한 줄 제목, 예: 전립선 MRI 구조화 판독 보조]
specialty: [아래 중 하나만 골라 쓰기]
author: [내 이름, 예: Sungil Hwang]
status: draft
data: synthetic
---

# [위 title 과 똑같이]

> 한 줄 요약: [이 도구가 무엇을 도와주는지]

## 무엇을 하나

[무엇을 넣으면 → 무엇이 나오는지, 한두 줄]

## 레시피

    [내가 실제로 쓰는 프롬프트를 여기에 붙여넣기]

## 주의사항

- 환자 정보는 넣지 않음. 비식별/합성 데이터만 사용.
- 임상 판단을 대체하지 않음. 최종 검토는 사람이 함.
```

**`specialty` 는 이 중 하나만 골라 적으세요:**
`radiology` `cardiology` `surgery` `pathology` `gyn-onc` `ent` `dentistry` `psychiatry` `oncology`
(어디에도 안 맞으면 `shared`)

> 더 자세히 쓰고 싶으면 Cookbook의 `recipes/_TEMPLATE/recipe.md` 에 전체 양식이 있어요. 위 최소 양식만으로도 충분합니다.
